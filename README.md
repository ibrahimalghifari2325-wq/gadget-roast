A one-line roast of an everyday gadget for the "One-Line Roast: The Gadget You Use Every Day" bounty on make.fun. The program writes a single roast (at most 200 characters) to `/output/entry.txt`, where the judge compares it head to head with the other entries.

## Run it

```sh
python3 main.py
```

That writes the roast to `/output/entry.txt`.
